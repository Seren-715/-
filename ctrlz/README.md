# Ctrl+Z — Never deploy on Friday (v2)

19 秒 / 16:9 / 60 fps / 无缝循环。画面是一个 three.js HTML 文件（`ctrlz.html`，字体内嵌，约 210 KB），声音由 numpy 合成。
每一帧都是时间 `t` 的纯函数（`window.renderAt(t, samples)`），随机数全部固定种子，所以任何一帧、任何机器、任何速度都画得一模一样。

## 在你自己的电脑上渲染

需要：Node 18+、ffmpeg、Python 3 + numpy。
GPU 机器上：16 采样 × 2 倍超采样的 1080p 每帧约 1–3 秒，全片 1140 帧约 20–60 分钟。

```bash
npm install
npx playwright install chromium
```
```bash
npm run preview            # 浏览器打开 http://127.0.0.1:8765/ctrlz.html  实时预览（空格暂停，←/→ 逐帧，R 重来）
```
```bash
node render.mjs --still 0.5,7.5,11.25          # 先渲几张定格看看 -> out/still_*.png
```
```bash
node render.mjs --timeline && python3 sound.py  # 声音 -> audio/ctrlz.wav
```
```bash
node render.mjs --ss 2 --samples 16             # 全片 -> out/chunks/*.mkv（FFV1 无损，可断点续渲）-> out/ctrlz.mp4
```

| 参数 | 作用 |
|---|---|
| `--samples 16` | 每帧 16 次采样：快门内时间（运动模糊）、镜头上的点（景深）、亚像素偏移（抗锯齿）、台灯灯泡上的点（软阴影） |
| `--ss 2` | 以 3840×2160 渲染再 Lanczos 缩到 1920×1080 |
| `--from 5 --to 9` | 只渲一段；已完成的分块自动跳过 |
| `--mux` | 只把已有分块编码成 H.264（High, CRF 14, 60 fps）并混入 AAC 声音 |
| `--checks` | 逐帧检查（见下），写入 `out/checks.json` |
| `--swiftshader` | 没有 GPU 时用软件渲染（很慢） |

如果 Playwright 的 Chromium 用不了你的 GPU，可以指定本机 Chrome：`CHROME_PATH=/path/to/chrome node render.mjs ...`。
修改了 `src/` 里的代码后，运行 `node build.mjs` 重新生成 `ctrlz.html`。

## v2 做了什么

- **拉伸镜头**：俯拍，Ctrl 和 Z 都读得出；Ctrl 前侧面还印了字（后腿踩在顶面上时也能读）。
- **Clawd**：超椭球软体（不是圆角盒），每次采样都重新变形——压扁时体积守恒、侧面鼓起；拉伸“太妃糖”从按在 Ctrl 上的后腿开始拉；
  表情贴片贴合身体曲面并反向缩放，拉伸时脸不变形；光泽墨水质感（clearcoat）；19 种表情；四条腿各自求解长度，脚始终踩在键帽表面。
- **键盘**：61 个雕刻键帽（每排高度和倾角不同、顶面下凹、底部空心带十字座），双字符印字，PBT 颗粒感；
  半透明轴体 + 十字轴 + 每颗 RGB LED；阳极氧化外壳、定位板、卫星轴；底部 RGB 灯带和桌垫光晕。
- **爆炸**：61 颗键帽是“反解”出来的闭式轨迹——先定好每颗在定格那一刻朝向镜头，再解旋转；按键盘布局在世界空间里扇形展开，轨迹互不交叉。
- **光**：左前方台灯是暖色主光（每次采样在灯泡表面抖动位置 → 真实软阴影），显示器是面光源（ERROR 时整个房间变红），辉光只作用于底灯。
- **后期**：ACES 色调映射、轻微色差、暗角、按亮度的胶片颗粒；VHS 倒带是后处理（扫描线、色度偏移、跟踪噪声带、磁头切换噪声），屏显放在左下角，永远不压显示器上的字。
- **声音**：196 个时间线事件，按键声由角色的脚实际踩到哪颗键自动生成（不是手写列表），每个按键声在键帽触底后 1 帧达到峰值。

## 实测结果（不是估计）

`node render.mjs --checks --sub 4`，全片 1140 帧 × 4 个子采样 = 4560 个时刻，用 OBB 分离轴检测：

| 检查 | 结果 |
|---|---|
| 键帽互相接触 | 0 |
| 键帽碰到 Clawd | 0 |
| 键帽碰到底板 / 外壳 | 0 |
| 着地的脚踩在键帽表面之外 | 0 |
| Clawd 挡住显示器上的字 | 0 |
| VHS 屏显压住显示器上的字 | 0 |
| 显示器的字被画面边缘切断 | 44 帧，全部在运动镜头中（甩镜 8.88–8.97、倒带 12.37–12.57、急推 16.77–16.85、拉回 17.43–17.63）；所有固定镜头里字要么完整、要么完全不在画内 |
| 小手点 Z | 指尖正好落在 Z 的顶面（误差 0.000），水平偏离中心 0.19/0.09 |
| 循环接缝 | 位置误差 1.5×10⁻⁶，速度差 0.007（典型速度 1.5） |
| Clawd 亮面颜色 | 实测 RGB(221,121,86)，目标 D97757 = (217,119,87) |
| 声音 | -14.1 LUFS，真峰值 -2.2 dBTP，限幅器最多压 6.8 dB |

## 如实说明

- 没有 Blender（云端装不上），Clawd 由代码建模，不是 GLB。
- 云端没有 GPU：只用软件渲染做了定格抽查，**16 采样的最终画质只在三张 1080p 定格上看过**（`preview/still_*.jpg`）。全片渲染没有在云端跑完，第一次完整渲染会在你电脑上；流程的每一步都在云端单独验证过：逐帧渲染→FFV1 分块，以及 `--mux`（用两段测试分块混出了 1920×1080 60fps H.264 + AAC 立体声、正好 19.000 秒的 MP4）。
- 声音我听不到，只做了测量。
- 字体：Inter Display 与 JetBrains Mono（SIL Open Font License 1.1），子集化后内嵌。
